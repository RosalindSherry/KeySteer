## 个性化改动

基于 [dccif/KeySteer v0.10.12](https://github.com/dccif/KeySteer/releases/tag/v0.10.12) 修改，增加重叠窗口之间的快速切换。

```toml
c = "window_activate_next_2"
x = "window_activate_previous_2"
```

### 切换规则

#### 1. 从哪个窗口开始

按下 `C` 或 `X` 时，优先选择鼠标光标下面的窗口；如果鼠标下面没有可识别窗口，才使用当前获得焦点的窗口。

它不是按照屏幕位置从左到右、从上到下识别，而是从鼠标所在的窗口开始。

#### 2. 怎样算同一组窗口

两个窗口的交叉区域同时满足以下条件，就会被认为属于同一个重叠窗口组：

- 横向重叠至少 `20px`
- 纵向重叠至少 `20px`

窗口只覆盖一部分也可以识别；完全被其他窗口遮住的普通窗口，只要没有最小化，通常也能识别。

目前采用连锁关联：如果 `A` 与 `B` 重叠、`B` 与 `C` 重叠，那么 `A、B、C` 会被视为同一组，即使 `A` 与 `C` 没有直接重叠。

#### 3. `C` 和 `X` 的切换顺序

第一次识别窗口组时，会按照 Windows 当前的窗口前后层级建立固定顺序。

例如当前层级为 `1、2、3`，其中 `1` 在最前面：

```text
C：1 → 2 → 3 → 1
X：1 → 3 → 2 → 1
```

程序会保留第一次得到的循环顺序，避免窗口激活后层级发生变化，导致只在两个窗口之间来回跳。

#### 4. 每次切换会发生什么

1. 找到目标窗口。
2. 将目标窗口激活并拉到最前面。
3. 原来的窗口退到后面。
4. 把鼠标移动到新窗口的正中心。
5. 下一次从这个新窗口继续循环。

#### 5. 不会加入切换的窗口

- 已经最小化的窗口
- 不与当前窗口组重叠的窗口
- 无法识别或无法激活的系统内部窗口、子控件和工具浮层
- 已经关闭的窗口
