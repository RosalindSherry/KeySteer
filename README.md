## 个性化改动

基于 [dccif/KeySteer v0.10.12](https://github.com/dccif/KeySteer/releases/tag/v0.10.12) 修改，增加不规则堆叠窗口组之间的快速切换。

```toml
c = "window_activate_next_2"
x = "window_activate_previous_2"
```
